# VCam VRM Converter — 手動 QA チェックリスト

Unity 側のテストは EditMode ユニットテスト (変換式・マッピング表) のみで、
実アバターの見た目・挙動は CI で検証できない。リリース前に以下を手動で確認する。

## 前提環境

- Unity 2022.3 LTS + VCC「Avatars」プロジェクト
- UniVRM v0.128.0 以上 (README 記載の検証済みバージョン)
- 検証用アバター: **lilToon マテリアル + PhysBone 髪 (+できればスカート)** を持つもの
- VCam (Web 版 `npm run dev` または Tauri 版)

## A. 変換フロー

- [ ] メニュー `VCam → VRChat → VRM 変換ウィザード...` が開く
- [ ] ライセンス確認チェックを入れるまで「検証を実行」以降が無効
- [ ] 「検証を実行」で Error / Warning / Info が一覧表示される
- [ ] Humanoid でないオブジェクトを選ぶと Error で変換に進めない
- [ ] 変換実行後、元アバターがシーン内で**一切変化していない** (Inspector で diff 確認)
- [ ] シーンに `〇〇_VRM` の複製が残る (設定 ON 時)
- [ ] `Assets/VCamVrmWork/<アバター名>/` に BlendShapeClip とマテリアルが生成される
- [ ] 再変換すると作業フォルダが作り直され、エラーにならない
- [ ] `.vrm` ファイルが指定場所に生成される

## B. VCam での読み込みと基本動作

- [ ] 生成した `.vrm` を VCam の dropZone に D&D → 「VRM 読込完了」が status に出る
- [ ] アバターが**前向き**に表示される (VRM0 の rotateVRM0 補正確認)
- [ ] 顔トラッキングで頭が追従する
- [ ] まばたきが反映される
- [ ] 🎙 マイク ON で口が開く (A 形状)
- [ ] 顔トラの口形 (aa/ih/ou/ee/oh) で口が動く
- [ ] 視線 (👀 ボタン) で目が動く ※目ボーンがあるアバターのみ

## C. マテリアル (元アバターとスクショ比較)

- [ ] 肌・髪・服の基本色が元とおおむね一致 (真っ黒/真っ白になっていない)
- [ ] 影色が出る (のっぺりしていない)
- [ ] アウトラインが出る (lilToon Outline バリアント使用時)
- [ ] エミッション (発光) が反映される ※該当アバターのみ
- [ ] 透過 (前髪・レース等) が抜ける。カットアウト (まつ毛等) のフチが破綻しない
- [ ] Poiyomi アバター: ロック済みで Error → Unlock 後に変換が通る

## D. 揺れもの

- [ ] 髪が首振りで揺れる
- [ ] 揺れが**発散しない** (激しく首を振っても暴れて戻らなくなることがない)
- [ ] スカートが脚に大きくめり込まない (コライダ変換確認) ※完全一致は仕様外
- [ ] 可動角 0 の PhysBone は揺れない (固定のまま)
- [ ] 「詳細設定」の係数変更が再変換に反映される

## E. 異常系

- [ ] viseme 未設定アバター: Warning が出た上で変換は成功し、口以外は動く
- [ ] UniVRM 未インストールのプロジェクト: ウィンドウ上部に Error 表示、変換不可
- [ ] テクスチャ巨大アバター (4K 多数): 70MB 超 Warning が出る

## F. VCam 側の回帰

- [ ] `npm run test` が green (本ツールは TS コードに触れないため影響なし想定)
- [ ] `npm run test:e2e` が green
- [ ] 既存の VRM (変換ツールを通していないもの) が今まで通り読み込める

## 既知の制限 (不具合ではない)

- PhysBone と SpringBone は物理モデルが異なるため、揺れの質感は一致しない
- ウィンク: 片目 BlendShape が無いアバターは両目まばたきで代用
- lilToon の HSV 補正・2nd/3rd カラー・階調影・ファー/屈折系は変換されない (Warning 表示)
- VRM の口形は 5 母音のみ (VRChat の残り 10 種 = 子音および無音 sil は破棄)
