# VRChat のアバターを VCam で使う方法

VCam は「VRM」という形式のアバターしか読み込めません。VRChat で使っている
アバターは別の形式なので、そのままでは使えません。このページでは、VRChat の
アバターを **VCam 公式の無料変換ツール「VCam VRM Converter」** で VRM に変換して
VCam に持ってくる手順を、できるだけ専門用語を減らして説明します。

> 💡 以前ここで案内していた有料ツール (VRM Converter for VRChat / 500 円) は
> 不要になりました。改変済みのアバターもそのまま変換できます。

---

## 🔤 先にざっくり用語

| 用語 | どういう意味か |
|---|---|
| **Unity** | 3D アプリを作るためのソフト。無料。アバターの変換作業で使います |
| **VRChat SDK** | VRChat 用のアバターを扱うための Unity 拡張。無料 |
| **UniVRM** | VRM を読み書きするための Unity 拡張。無料。変換ツールが内部で使います |
| **VRM** | VCam が読めるアバターのファイル形式。拡張子は `.vrm` |
| **Humanoid (ヒューマノイド)** | 「人間の形」として認識されたアバター。腕が 2 本、脚が 2 本、というような |
| **BlendShape (ブレンドシェイプ)** | 表情を切り替える仕組み。「口を開く」「目を閉じる」などが登録されている |
| **シェーダ** | アバターの肌の質感や光の当たり方を決める仕組み。VRChat と VRM で互換性がないことがある |
| **揺れもの / PhysBone** | 髪やスカートが自然に揺れる仕組み。VRChat と VRM では別物 (ツールが自動で近似変換します) |

## ⚠️ いちばん大事: ライセンスを読もう

**作業を始める前に、アバターの利用規約を必ず読んでください。**

Booth などで買ったアバターには「使っていい範囲」が決まっています。次のような
ことが書いてある場合は VCam では使えません:

- **「VRChat 以外での利用は禁止」** ← VCam は VRChat ではないので NG
- **「VRM への変換を禁止」** ← そのまま NG
- **「改変禁止」** ← 厳密に解釈すると VRM 化も NG になり得る

許可の例:
- 「VRM 化 OK」「他ツール利用 OK」と **明記** されている
- 「個人利用の範囲で改変 OK」
- 「VRoid Hub にアップロード OK」(これがあれば VRM 変換は OK)

不明なら、作者さんに Twitter や Booth のメッセージで **「自分の PC で VRM に
変換して使ってもいいですか」** と聞くのが確実です。返事を待てない / 規約に無い
場合は、別の VRM 対応アバターを探したほうが安全です。

> 変換ツールにも同じ内容の確認チェックがあります。チェックを入れないと
> 変換に進めません。また、書き出される VRM のメタ情報は既定で
> 「再配布禁止」になります (事故防止のため)。

## 🪜 手順 (クリックごとに書いています)

### ステップ 1: Unity を入れる

1. https://unity.com/download から **Unity Hub** をダウンロードして起動
2. Unity Hub の左側 **「Installs」** → **「Install Editor」**
3. **Unity 2022.3 LTS** を選んでインストール (30 分ほどかかります)

> 💡 「どれを選べばいい?」 → **必ず 2022.3 LTS**。他のバージョンだと VRChat SDK
> が動かないことがあります。

### ステップ 2: VRChat Creator Companion (VCC) を入れる

1. https://vrchat.com/home/download から VCC をダウンロードして起動
2. **「New」** → **「Avatars」** テンプレートを選んで新しいプロジェクトを作成
3. プロジェクト名を `VRM-Convert` など分かりやすい名前に

これで、Unity の中に VRChat SDK が入った空のプロジェクトができます。

> 💡 すでに改変作業をしているプロジェクトがあるなら、それをそのまま使って OK
> です。その場合このステップは飛ばしてください。

### ステップ 3: アバター用のファイルを読み込む

(改変済みプロジェクトを使う場合は飛ばしてください)

1. **「Open Project」** をクリックすると Unity が立ち上がります
2. 画面下の **「Project」** パネルの `Assets` フォルダへ、購入したアバターの
   `.unitypackage` ファイルを **ドラッグ&ドロップ**
3. 出てきた確認画面で **「Import」** (全部チェックが入っている状態のまま)
4. 数分待ったら、`Assets` の下にアバターのフォルダができます
5. アバターのフォルダの中にある **Prefab ファイル** (四角いキューブのアイコン
   のやつ) を、画面左上の **「Hierarchy」** パネルにドラッグ&ドロップ
6. アバターが画面中央に現れれば成功

### ステップ 4: UniVRM と変換ツールを入れる

どちらも Unity の **Package Manager** から URL を貼るだけで入ります。

1. Unity のメニュー **「Window」→「Package Manager」** を開く
2. 左上の **「+」** ボタン → **「Add package from git URL...」**
3. 次の 3 つの URL を、**上から順に 1 つずつ** 貼って「Add」(各 1〜2 分待つ):

```
https://github.com/vrm-c/UniVRM.git?path=/Assets/UniGLTF#v0.128.0
https://github.com/vrm-c/UniVRM.git?path=/Assets/VRM#v0.128.0
https://github.com/Fuwaaaaaa/VCam.git?path=unity/jp.vcam.vrm-converter
```

> 💡 1 つ目と 2 つ目が **UniVRM** (VRM の読み書き部品)、3 つ目が
> **VCam VRM Converter** (本ツール) です。順番が大事です。

4. Unity のメニューバーに **「VCam」** が増えていれば成功

> 💡 **UPM git URL がうまくいかない場合**: 本ツールはリポジトリの
> `unity/build-unitypackage.ps1` で `.unitypackage` を生成できます (現状、
> GitHub Releases への自動公開はありません)。生成した
> `VCamVRMConverter-x.x.x.unitypackage` を Unity の `Assets` にドラッグ&ドロップ
> → 「Import」でも導入できます。その場合も 1 つ目・2 つ目の UniVRM は URL で
> 先にインストールしてください。

### ステップ 5: 変換ウィザードを実行する

1. メニュー **「VCam」→「VRChat → VRM 変換ウィザード...」** を開く
2. ウィンドウの指示に沿って上から順に進めます:
   - **アバターを選ぶ**: Hierarchy のアバター (ルート) をドラッグして指定
   - **ライセンス確認**: 規約を確認したらチェックを入れる
   - **検証を実行**: 問題があれば赤いエラーで表示されます。直してから再実行
   - **変換の設定**: タイトル (アバター名)・バージョン・自分の名前を入れる。
     マテリアル変換・揺れもの変換、および「変換後の複製をシーンに残す」は
     ON のままで OK
3. **「変換して .vrm をエクスポート」** をクリック
4. 保存先を聞かれるので、分かりやすい場所 (デスクトップ等) に保存
5. `.vrm` ファイルが生成されれば完了 🎉

> 💡 元のアバターは一切変更されません。変換はシーン内に作られる複製
> (`〇〇_VRM`) に対して行われます。

### ステップ 6: VCam に読み込ませる

1. VCam アプリを起動
2. 画面左下の「ここに **.vrm** をドラッグ&ドロップ」と書かれた枠に、
   生成した `.vrm` ファイルをドラッグ&ドロップ
3. アバターが画面中央に現れて、顔を動かすと反応するようになれば OK

## 🚨 よくあるトラブルと対処

### Q1. アバターが **真っ黒 / 真っ白** で何も見えない

A. 本ツールは lilToon / Poiyomi のマテリアルを自動で MToon (VRM 用) に変換する
ため、通常は起きません。それでも起きる場合:

- ウィザードの「検証を実行」や変換後の警告に **「変換方法が不明」** と出ていた
  シェーダは変換されていません。Unity で該当マテリアルを「Standard」か
  「VRM/MToon」に変えてから再変換してください
- Poiyomi で **「ロックされています」** とエラーが出た場合は、マテリアルを
  右クリック → **Thry → Unlock Material(s)** してから再変換

### Q2. **髪やスカートが揺れない / 揺れ方が変**

A. VRChat の「PhysBone」は本ツールが VRM の揺れもの (SpringBone) に自動変換
しますが、**計算方法が違うため揺れ方は完全には一致しません**。

- 揺れすぎる / 揺れない場合は、ウィザードの **「詳細設定 (揺れの係数)」** で
  係数を調整して再変換してください
  - 揺れすぎ → 「Spring を反転して減衰にする」を ON
  - 硬すぎ → 「Pull → 硬さ 係数」を下げる
- まったく揺れない場合、その PhysBone の可動角が 0 (固定) になっていないか
  確認してください

### Q3. **口がほとんど動かない** (リップシンクが弱い)

A. VRChat は 15 種類、VRM は 5 種類の口の形を使うため、母音以外の口形は変換
されません。VCam 側の「🎙 マイク」ボタンを ON にすると、マイク音量で口が大きく
開くようになるので、マイク ON で使うのがオススメです。

ウィザードの検証で「リップシンク (Viseme) が未設定」と警告が出ていた場合は、
VRCAvatarDescriptor の LipSync 設定を確認してください。

### Q4. **アバターが巨大 / 小さすぎ**

A. 変換時に自動で正規化されますが、ルートの Scale が極端な場合は検証で警告が
出ます。Unity でアバターの **Scale** を `1, 1, 1` に合わせてから再変換して
ください。Hierarchy でアバターを選択 → 右の Inspector の上のほうに Scale が
あります。

### Q5. **検証で「Humanoid ではありません」とエラーが出る**

A. アバターの元モデル (FBX) を選んで Inspector で **「Rig」** タブ →
**「Animation Type」** を `Humanoid` に変えてください。その後 **「Apply」** を
押してから変換作業を再開。

### Q6. **ウィンクすると両目が閉じる**

A. VRChat のまばたき設定は「両目同時」しか持たないため、片目用の BlendShape
(`blink_l` / `blink_r` など) がメッシュに無いアバターでは両目まばたきで代用
します。VCam は通常両目同時にまばたきさせるので、実用上はほぼ問題ありません。

### Q7. **Unity の操作が複雑で詰まった**

A. 無理せず、**VRM 対応のアバターを最初から探す** のが楽です。以下のサイトで
VRM 形式のアバターが手に入ります:

- [VRoid Hub](https://hub.vroid.com/) — 「再配布 OK」で絞り込むと安全
- [VRoid Studio](https://vroid.com/studio) — 無料ツールで自作できる
- [ニコニ立体](https://3d.nicovideo.jp/) — VRM 同梱モデル多数
